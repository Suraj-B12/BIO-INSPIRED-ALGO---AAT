\chapter{Conclusion}
This project connected a from-scratch Differential Evolution implementation to a transfer-learning CNN for tomato leaf disease classification. Training settings were chosen on validation data only, and the final models were tested once on held-out images.

The cleaned dataset contains \TotalN\ images. The benchmark study completed \TotalBenchmarkRuns\ optimiser runs and \TotalBenchmarkEvaluations\ function evaluations. It confirmed that our DE works correctly and showed that each method has landscapes where it does best.

On the tomato task, DE raised mean test accuracy from \BaseAcc\% to \DEAcc\% and macro-F1 from \BaseFone\% to \DEFone\%, removing \ErrorReduction\% of the baseline's errors. Every class improved, and the McNemar test ($p=\McNemarP$) confirms that the improvement is not due to chance. Random search with the same number of trials reached the same accuracy, which confirms that tuning the training recipe is what drives the gain; DE matched this strong control and led it during the search.

The objectives from Chapter~1 were met as follows:
\begin{enumerate}
\item The dataset was cleaned, documented, and split fairly, with the split lists saved in the repository.
\item DE was implemented from scratch, unit-tested, and validated on five test functions.
\item The baseline, DE, and random search were compared under the same rules and number of trials.
\item The final models were evaluated over three seeds, per class, with confidence intervals, a significance test, corruption tests, and Grad-CAM.
\item A working offline demo, this report, slides, and reproducible code were delivered.
\end{enumerate}

\textbf{Limitations.} The results come from PlantVillage, whose photos were taken under controlled conditions, and from one search run per method. Testing on field photos and making the model more robust to poor-quality images are the main next steps, described in Chapter~11.
