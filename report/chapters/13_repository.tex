After creating a Python environment and installing the documented dependencies, the cross-platform entry point is \texttt{python run\_all.py}. A synthetic smoke run uses \texttt{python run\_all.py --smoke}. Existing result figures can be reproduced without retraining through \texttt{python scripts/09\_figures.py}; tables are regenerated by \texttt{python scripts/10\_make\_tables.py}. Start the installed demo with \texttt{python demo/serve.py} and open its printed local address.

The workflow configuration targets macOS, Linux, and Windows. A CI configuration is not itself proof that every operating-system run passed; consult the actual repository Actions run and the verification report for observed status. Full experiment reproduction also requires the original data source and pretrained weights to be available during setup. Once installed and equipped with the final checkpoints, the demo operates offline.
