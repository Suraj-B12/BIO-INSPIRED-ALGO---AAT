\chapter{Conclusion}
This project connects a from-scratch Differential Evolution implementation to an auditable transfer-learning workflow and an offline interactive demonstration. The fixed backbone is EfficientNet-B0, the dataset is PlantVillage's tomato subset, and the decision vector contains training and classifier/fine-tuning parameters. The evaluation design protects the held-out split from model selection and compares adaptive search with an equal-budget random control.

Data preparation retained \TotalN\ usable images after documented cleaning. The analytic study completed \TotalBenchmarkRuns\ optimizer runs with \TotalBenchmarkEvaluations\ objective calls. The median DE Sphere error was \SphereDE. These measured artifacts validate important components independently of the final CNN comparison.
