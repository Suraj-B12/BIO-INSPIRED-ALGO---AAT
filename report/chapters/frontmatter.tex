\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
Plant leaf classification is a useful test case for studying how nature-inspired optimization can improve a deep-learning training recipe. This project builds a reproducible system for tomato disease classification using ImageNet-pretrained EfficientNet-B0 and Differential Evolution (DE). The backbone family, dataset, baseline, and evaluation protocol are fixed before model selection. A normalized chromosome controls learning rate, weight decay, dropout, classifier width, fine-tuning depth, label smoothing, and augmentation strength. DE/rand/1/bin is implemented from scratch with distinct donors, parent-to-bound repair, forced binomial crossover, greedy selection, and resumable state.

The cleaned dataset contains \TotalN\ images, with \TrainN, \ValN, and \TestN\ assigned to training, validation, and held-out testing. Group-aware splitting reduces leakage from similar images. Candidate fitness is validation macro-F1 at proxy fidelity; final configurations are selected after higher-fidelity reranking and trained over the same repeated-seed protocol. Random search provides an equal-budget control. Evaluation includes per-class metrics, bootstrap intervals, paired classifier comparison, calibration, image-corruption stress tests, and Grad-CAM. Separate analytic benchmarks assess the optimizer independently of neural training.

\ifnum\ResultsComplete=1\relax
The final baseline, DE, and random-search accuracies are \BaseAcc\%, \DEAcc\%, and \RSAcc\%, respectively; their macro-F1 scores are \BaseFone\%, \DEFone\%, and \RSFone\%. The paired seed-zero comparison yields McNemar $p=\McNemarP$. These measurements describe the specified held-out distribution, not unrestricted field reliability.

The current build reports completed data preparation and optimizer benchmarks; final neural-network results remain explicitly pending. No anticipated accuracy is substituted for a measured result.
\fi

An offline interactive demo connects diagnosis, model comparison, and visible DE evolution to the underlying evidence. The system emphasizes auditability and honest interpretation over unsupported claims of universal superiority.
